# Employee Sales Performance Dashboard 📊

An interactive Power BI dashboard designed to analyze employee sales trends, target achievements, regional distribution, and top-performing product categories.

---

## 📌 Key Metrics & Highlights
- **Total Sales:** 240M
- **Target Sales:** 27M
- **Overall Target Achievement:** 903.08%
- **Units Sold:** 25.27K

---

## 🔍 Visualizations & Insights
1. **Sales by Employee:** Performance comparison across sales representatives (e.g., Anjali Roy, Sneha Nair, Aarti Saxena).
2. **Sales by Region:** Regional revenue contribution across North, South, East, Central, and West.
3. **Monthly Trend Analysis:** Tracking revenue fluctuations across months.
4. **Category & Product Performance:** Analysis across categories (Furniture, Books, Electronics, Home Appliances, Clothing) and top products.

---

## 🛠️ Tools & Technologies Used
- **Power BI Desktop:** Interactive dashboard building, DAX measures, and data modeling.
- **Excel / CSV:** Primary dataset storage and data cleaning.
